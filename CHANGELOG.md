# Changelog

## [1.0.0] - 2026-10-16
### Added
- HMAC-SHA256 URL signing engine with constant-time signature verification.
- Time-based expiration validation and view consumption limiter.
- Emergency token-level and document-level revocation kill switches.
- Reference HTTP server and interactive browser dashboard with dynamic watermark display.
- Unit test suite testing valid tokens, tampered signatures, expired tokens, and immediate revocation.
